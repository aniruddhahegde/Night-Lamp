# Night-Lamp
It is a simple basic lamp which lights up when the surrounding is dark.I have used LDR sensor to detect darkness,a transistor,diode and a 6V power source.I designed PCB using KiCad. Related Files are uploaded above.
So what happens the LDR as soon as darkness occurs,the resistance of LDR decreases and current can pass through it.
Now almost 16mA current will flow hence 330 ohm resistor been taken.
The estimation,Bill of materials been added in the files above.
The improvement we can make is adding some sort of sound effects will make it more effective.
